## 三、三區固定佈局（Shell Layout）

> ⚠️ **全系統所有頁面必須套用三區固定佈局，不得例外**（GUIDED 介面除外）

```
┌─────────────────────────────────────────────┐
│  TOP BAR（固定，不捲動）高度 56px              │
│  [返回🟢] ── 介面名稱 ── [語系] [使用者] [登出🔴]│
├─────────────────────────────────────────────┤
│                                             │
│  CONTENT AREA（唯一捲動區）flex: 1            │
│  overflow-y: auto                           │
│                                             │
├─────────────────────────────────────────────┤
│  BOTTOM NAV（固定，不捲動）                   │
│  高度：手機 64px / 平板+ 58px                │
│  [基本資料] [作業系統] [資料查詢] [報表]       │
└─────────────────────────────────────────────┘
```

### CSS 骨架

```css
.app-shell {
  height: 100vh;
  display: flex;
  flex-direction: column;
  overflow: hidden;
  max-width: 1280px;
  margin: 0 auto;
}

.top-bar       { flex-shrink: 0; height: 56px; }
.content-area  { flex: 1; overflow-y: auto; }
.bottom-nav    { flex-shrink: 0; }
```

### Top Bar 圖示顏色

|按鈕   |顏色                       |說明     |
|-----|-------------------------|-------|
|← 返回 |`#2dd4bf`（–color-success）|有上頁時才顯示|
|→ 登出 |`#f87171`（–color-danger） |永遠顯示   |
|語系切換 |`--color-text-muted`     |TH / 中 |
|使用者名稱|`--color-text-muted`     |平板+才顯示 |

### 路由規則

所有作業系統與基本資料的子頁面，必須以 AppShell layout 為父層渲染，確保 Top Bar 與 Bottom Nav 持續顯示。子頁面內容只替換 Content Area，不得替換整個頁面。

## 五、頁面流程與導航

### Master Data 流程（不變）

```
底部導航選取「基本資料」
    │
    ▼
模組選單（10個模組卡片，平板2欄 / 手機2欄2×5）
    │
    ▼
點選模組（如農民名冊）
    │
    ▼
項目 Grid 列表（圖像+ID+名稱卡片）
    ├── 右上角 [新增] 按鈕
    └── 點選卡片 → 明細抽屜開啟
                    ├── 唯讀明細顯示
                    ├── [編輯] → 切換為可編輯表單
                    └── [刪除] → 確認 Dialog → 軟刪
```

### Operations 作業系統流程（導引模式）

```
底部導航選取「作業系統」
    │
    ▼
模組選單（進貨 / 加工 / 代工 / 包裝 / 運輸 / 銷售 / 採購 / 監控）
    │
    ▼
進入模組（如進貨系統）
    │
    ▼
主單列表（Content Area）
    ├── 右上角 [新增主單] 按鈕
    └── 點選主單卡片 → 進入主單明細頁
```

### 返回鍵邏輯（Top Bar 左側）

```
在導引選取步驟中   → 返回上一步驟
在主單明細頁      → 返回主單列表
在主單列表       → 返回作業系統模組選單
在模組選單       → 不顯示返回鍵
```

## 十一、數字鍵盤規格（NumericKeypad）

### 外觀

- 底部滑入覆蓋層（`transform: translateY`，transition 動畫）
- 大字顯示目前輸入值（fontSize 32px）
- 按鍵：1-9、0、小數點（`.`）、退格（←）、清除（C）、確認（✓）

### 防呆規則

|規則       |說明                          |
|---------|----------------------------|
|小數點最多 1 位|輸入第 2 位小數時禁止，按鍵無反應          |
|允許輸入 0   |可以輸入 0 或 0.0 等              |
|不允許負數    |無負號按鍵                       |
|無最大值限制   |不設上限                        |
|開頭防呆     |不允許多個前導零（如 007 → 禁止，07 → 禁止）|
|小數點唯一    |已有小數點時，再按小數點無反應             |

### Mode 規格

|Mode     |說明            |
|---------|--------------|
|`decimal`|允許小數點，最多 1 位小數|
|`integer`|不顯示小數點按鍵，只允許整數|

## 十三、系統提示元件

### Toast 通知

- 位置：Content Area 底部中央，底部 Nav 上方 72px
- 成功：深綠背景 `#1a4a2a`
- 失敗/刪除：`--color-danger-bg`
- 圓角：10px，顯示 2.2 秒自動消失

### Delete 確認 Dialog

- 全螢幕半透明遮罩 `rgba(0,0,0,0.65)`
- 卡片式彈窗，最大寬 360px
- 內含：標題、說明文字、[確認刪除] + [取消] 按鈕

### 網路斷線提示（依角色不同）

#### 一般角色（ADMIN / OFFICE / FACTORY）

- 觸發：`navigator.onLine === false` 或 `offline` 事件
- **全螢幕覆蓋，無法手動關閉**，z-index 最高
- 網路恢復後自動關閉

```
外觀：全螢幕覆蓋，背景 rgba(0,0,0,0.92)
中央顯示警告圖示 + 泰語文字：

⚠️ เครือข่ายขัดข้อง!
พนักงานทุกคนหยุดปฏิบัติงาน
กรุณาบันทึกด้วยกระดาษและปากกาก่อน
เมื่อเครือข่ายกลับมาใช้งานได้ ค่อยบันทึกข้อมูลในระบบ
กรุณาติดต่อ Poli หรือ Jeab
```

#### GUIDED 角色（Yowthi）— 離線橫幅

- **不封鎖操作**，改顯示頂部小橫幅
- 背景：`--color-warning-bg`（#f59e0b）
- 文字：泰語「กำลังออฟไลน์ – ข้อมูลบันทึกในเครื่อง」（離線中，資料存本地）
- 網路恢復後自動消失，並顯示上傳完成 Toast

## 十四、作業系統模組佈局規範（Operations Layout）

> 適用：進貨、加工、代工、包裝、運輸、銷售、採購等所有作業系統模組

### 14-1 主單列表頁

主單卡片顯示資訊（以進貨單為例）：

- 進貨品項圖片（48px 圓角方形）
- 進貨單序號（橘色，粗體）
- 進貨日期（D/M/YY 格式）
- 進貨品項名稱
- 明細總數量
- 明細總金額
- 狀態 Badge（如 H02 / H03 完成狀態）

圖片顯示規則：

- 有 imageUrl → 顯示品項圖片
- 無 imageUrl → 顯示品項名稱前兩字作為 Avatar（依 ID charCode 決定背景色）

### 14-2 新增主單 — 導引模式（全作業系統統一）

按下「新增主單」後，**不使用下拉選單**，改用**全螢幕導引步驟模式**：

#### 電腦版（≥ 1024px）

```
┌────────────────────────────────────────────────────┐
│  TOP BAR（固定）                                    │
├──────────────┬─────────────────────────────────────┤
│              │                                     │
│  左側         │  右側                               │
│  步驟導引區   │  操控區                              │
│  （固定）     │  （可捲動）                           │
│              │                                     │
│  Step 1 ●   │  當前步驟的選取或輸入介面               │
│  Step 2 ○   │                                     │
│  Step 3 ○   │                                     │
│  ...         │                                     │
│              │                                     │
├──────────────┴─────────────────────────────────────┤
│  BOTTOM NAV（固定）                                 │
└────────────────────────────────────────────────────┘
```

- 左側步驟區寬度：220px，固定不捲動
- 右側操控區：flex: 1，overflow-y: auto

#### 手機 / 平板直立（< 1024px）

```
┌─────────────────────────────┐
│  TOP BAR（固定）              │
├─────────────────────────────┤
│  步驟進度條（頂部橫向，精簡顯示） │
│  Step 2/5：選取農民            │
├─────────────────────────────┤
│                             │
│  操控區（可捲動）              │
│  當前步驟的選取或輸入介面        │
│                             │
├─────────────────────────────┤
│  [上一步]        [下一步/確認] │
├─────────────────────────────┤
│  BOTTOM NAV（固定）           │
└─────────────────────────────┘
```

- 步驟進度條：顯示「Step N/Total：步驟名稱」
- 底部固定導航按鈕：[上一步] 左側 / [下一步 / 確認] 右側
- 每次只顯示一個步驟的操控介面，步驟間以動畫切換

### 14-3 導引選取元件（TouchSelectorModal）

所有作業系統模組的選取操作，統一使用 **TouchSelectorModal** 跳出視窗，禁止使用 HTML `<select>` 下拉選單。

#### 外觀規格

```
┌─────────────────────────────────────┐
│  MODAL HEADER                       │
│  選取農民                    [✕]    │
├─────────────────────────────────────┤
│  [🔍 搜尋 ID 或姓名...           ]  │
├─────────────────────────────────────┤
│                                     │
│  卡片 Grid（可捲動）                 │
│  ┌──────┐  ┌──────┐  ┌──────┐      │
│  │ 圖片  │  │ 圖片  │  │ 圖片  │      │
│  │ ID   │  │ ID   │  │ ID   │      │
│  │ 姓名  │  │ 姓名  │  │ 姓名  │      │
│  └──────┘  └──────┘  └──────┘      │
│                                     │
└─────────────────────────────────────┘
```

#### 卡片規格

|項目   |規格                              |
|-----|--------------------------------|
|圖片   |48px × 48px 圓角方形，無圖片時顯示 Avatar  |
|ID   |11px，`--color-text-muted`，Tag 樣式|
|姓名   |13px，`--color-text`，粗體          |
|卡片尺寸 |適中，每列 3 欄（桌面）/ 3 欄（平板）/ 2 欄（手機） |
|選取狀態 |橘色邊框 + 淡橘背景 + 右上角勾選圖示           |
|點選即確認|點選卡片直接確認選取，關閉 Modal             |

#### 搜尋規格

- 搜尋框在 Modal 頂部，自動 focus
- 即時篩選：輸入 ID 或姓名的任意部分
- 搜尋結果即時更新，無需按確認鍵
- 清空搜尋時顯示全部

#### Grid 規則

|裝置|欄數 |
|--|---|

### 14-6 新增進貨單導引步驟

```
Step 1：選取進貨日期
    → DatePicker（可補單，不限當天）

Step 2：選取進貨品項
    → TouchSelectorModal（圖片 + ID + 名稱）
    → 系統自動判斷當日是否已有該品項進貨單
       ├─ 已有 → 提示「當日已有進貨單 S-XXXXXX，是否繼續新增明細？」
       └─ 沒有 → 自動產生新序號，進入 Step 3

Step 3：選取農民
    → TouchSelectorModal（圖片 + ID + 姓名，搜尋框）

Step 4：輸入數量
    → NumericKeypad 自動彈出（decimal 模式）

Step 5：輸入單價
    → NumericKeypad 自動彈出（decimal 模式）
    → 系統自動計算金額 = Math.floor(數量 × 單價)

Step 6：確認儲存
    → 顯示確認摘要（農民 + 數量 + 單價 + 金額）
    → [儲存] → 儲存並詢問「是否繼續新增同張進貨單的明細？」
       ├─ 繼續 → 返回 Step 3（保留同張進貨單，重新選農民）
       └─ 完成 → 返回主單列表
```

> 同一農民同日若有多次送貨，重複選取同一農民，系統自動遞增 batchNo

## 十九、手機觸控與縮放規格

- 全系統觸控操作使用 `touch-action: manipulation`，允許單指捲動及雙指縮放，但禁止快速連點被瀏覽器判定為雙擊放大。
- 數字鍵盤按鍵必須另外套用 `touch-action: manipulation` 與 `user-select: none`，連續輸入相同數字不得造成畫面縮放或文字選取。
- 手機及觸控裝置的原生 `input`、`textarea`、`select` 字級不得小於 16px，避免 iPhone 聚焦輸入框時自動放大頁面。
- 不使用 `user-scalable=no` 或 `maximum-scale=1` 全面禁止縮放，必須保留使用者主動雙指縮放的無障礙能力。
